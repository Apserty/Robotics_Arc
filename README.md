# Robotics_Arc

# 🤖 Robotics Learning Journey

A hands-on repository tracking my journey into robotics fundamentals, hardware experimentation, kinematics, and control systems.

## 📌 Overview
This repository documents my progression from the basics of robotics to building autonomous systems. It serves as a central hub for code snippets, simulation setups, hardware interfacing, and mini-projects.

## 🛠️ Focus Areas & Tech Stack
* **Hardware & Microcontrollers:** Arduino, ESP32, Raspberry Pi, Motor Drivers (L298N/PCA9685)
* **Simulation & Middleware:** ROS 2 / Gazebo, Webots
* **Programming Languages:** C++, Python
* **Core Concepts:** Forward/Inverse Kinematics, Sensor Fusion (IMU, Ultrasonic, LiDAR), PID Control, State Machines
